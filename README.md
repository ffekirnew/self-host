# self-host.

Home server stack run with Docker Compose, exposed through a Cloudflare tunnel.

## Prerequisites

- `docker` with the Compose v2 plugin (`docker compose`)
- `make`
- `bash`
- `.env` in the repo root (`cp .env.example .env` and fill in) containing:
  ```
  CLOUDFLARE_TUNNEL_TOKEN=<token>
  NORDVPN_USER=<service username>
  NORDVPN_PASSWORD=<service password>
  TANDOOR_SECRET_KEY=<generated by bootstrap>
  TANDOOR_DB_PASSWORD=<generated by bootstrap>
  WEBUI_SECRET_KEY=<generated by bootstrap>
  ```
  The NordVPN values are the *service credentials* from Nord Account → NordVPN → Manual setup, not your login.

## Usage

```sh
make up   # runs ./bootstrap.sh, then starts everything
```

`./bootstrap.sh` checks the prerequisites above, creates the `proxy` Docker network if it doesn't exist yet, and runs each service's `<service>/bootstrap.sh`, which creates that service's host directories and checks its config. It's safe to re-run.

## Access

Public services go through the Cloudflare tunnel only and publish no host ports. Tandoor (recipes) is public at `recipes.ffserver.cc` with its own login; use the kitshn app (iOS/Android) as a client. Open WebUI (local LLM chat on Ollama) is public at `chat.ffserver.cc` with its own login; signups are off. Admin UIs are bound to `127.0.0.1`:

| Service | Port | Role |
| --- | --- | --- |
| Seerr | 5055 | request movies/TV; public at `seerr.ffserver.cc` |
| Sonarr | 8989 | TV |
| Radarr | 7878 | movies |
| Lidarr | 8686 | music |
| Bazarr | 6767 | subtitles |
| Prowlarr | 9696 | indexers (synced to Sonarr/Radarr/Lidarr) |
| qBittorrent | 9090 | downloads |

From another machine: `ssh -L 8989:localhost:8989 <server>` (one `-L` per port).

qbittorrent shares gluetun's network namespace, so all of its traffic goes through NordVPN. If the VPN drops, it has no network.

## Media layout

Everything lives under one folder so finished downloads can be hardlinked into the library (instant, no extra disk):

```
~/home-server/data/
├── torrents/{tv,movies,music}   # qbittorrent categories
└── media/{tv,movies,music}      # library: Jellyfin, Navidrome
```

Containers that need both mount it as `/data`.

## Local LLMs

Ollama runs models on the Intel iGPU (Vulkan). Small models only: `qwen3:4b` (~4 tok/s) and `llama3.2:1b` (~9 tok/s).

```sh
docker exec ollama ollama pull <model>   # add a model
docker exec ollama ollama list           # list models
```
